This is the Seed Desktop version of autogen. The link for PyPI is https://pypi.org/project/seed-autogen/.

For installation, use

```
pip install seed-autogen
```

Check https://github.com/ag2ai/ag2 for ag2, or https://github.com/microsoft/autogen for microsoft autogen.

## Update and Version Control

Updates and modifications will initially be made on the seed-feat branch.

The seed-main branch will maintain the most stable version. Updates and modifications can only be merged into it after successful testing on Test PyPI.
